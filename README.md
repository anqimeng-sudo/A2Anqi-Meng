## Project Overview
## Coding Environment: Processing – Java Mode
This is an interactive visual art prototype made with Processing, with an ocean theme. The screen can switch directly back and forth between grey and colour.
## How It Works
When the user clicks anywhere on the screen, the scene swithches between grey and colour.
## How to Run
Open the .pde file in Processing using Java Mode and click Run. A grey screen will appear. Then, click anywhere on the screen to switch back and forth between grey and colour.
## Main Code Concepts
The main code I used for this assignment is boolean, if/else, mousePressed(), and the ! operator.
## Sources/Acknowledgements
I used the Processing Foundation's Mouse Functions example to understand mousePressed().
Mouse Functions：https://processing.org/examples/mousefunctions.html
I used the Logical Operators example to understand how the ! operator switches the boolean state between true and false.
